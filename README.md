# Vernacular Maths Assistant — Prototype

## Scope
- Class 3 Mathematics
- Hindi input
- Santali output in Ol Chiki where available
- Local Excel dataset for the first prototype
- BHASHINI NMT will replace the local translation layer after API approval

## Run
1. Put `app.py`, `requirements.txt`, and the Excel file in the same folder.
2. Open a terminal in this folder.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Start Streamlit:

```bash
streamlit run app.py
```

## Important
This is a prototype. The dataset's README says language-specific translations still require native-speaker validation. Do not claim the entire dataset is validated.

No API credentials are stored in this project.
